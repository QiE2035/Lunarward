### 2.1 运行器段

字段：名字、版本、布局（`bin` / `files-bin`）、可用性（`可用` / 具体原因）、`用于 N 个方案`、路径（可复制）。

- 可用性原因沿用现有 `ComponentStore.EvaluateRunner` 四条：找不到可执行文件 / 没有执行权限 / `wine --version` 无输出 / 找不到配套 wineserver。
- 「添加路径…」= 选一个 `wine` 可执行文件，做一次 `--version` 探测，成功则写进「手动添加」列表（存 `~/.config/lunarward/manual-runners.json`，与扫描结果合并，标注「手动」）。**不复制文件**、不改系统。
- 不提供下载/市场（D58 v2 已收回）。

### 2.2 方案段

每行：方案名、运行器名、图形层（`DXVK x.y` / `无`）、前缀标签（`专用` / `使用已有` / `复制自 …` / `临时`）、`绑定：游戏列表`、`上次启动 <时间> 成功/失败`。

- 「上次启动」来自 `LastKnownGoodStore` + 最近一份 `logs/launch/*.json` 的 `CanLaunch`。
- `[编辑]` → 进入方案编辑页（见 §3）。`[诊断]` → 直接跑该方案的预检并弹现有对话框（可点修复）。
- 旧配置里若有 `shared` 模式，行上显示 `共用（旧配置）`，编辑页里只能改成其余四种。

### 2.3 前缀段

每行：来源标签 + 关联游戏、大小、`N 个方案使用`、状态、路径、操作。

- 状态判定：目录不存在 → `不存在`；缺 `drive_c` 或 `system.reg` → `缺少 drive_c`；`.lunarward/lock` 可写但被占 → `正被占用`；否则 `健康`。
- `[清理]` 仅对我们创建的前缀（`dedicated` / `template` 复制品 / `ephemeral` 残留）出现，且要求前缀未被任何方案引用、未被占用；删除前二次确认。
- 外部前缀（`external`）只显示，不提供清理。

## 3. 方案编辑页（`RuntimeProfileEditorPage`）

整页，`Frame.Navigate` 进入，左上返回。四段纵向，底部固定 `取消` / `保存`。

```
← 默认（opt）
──────────────────────────────────────────────
运行器
  [ spritz-wine-tkg-staging  10.0  可用 ▾ ]
  路径 /opt/spritz-wine-tkg/bin/wine          [复制]
  ⚠ 原来的运行器已不可用 → [换回默认]  [从索引下载（未实现，禁用）]

图形层
  [ DXVK 2.7 ▾ ]   [ VKD3D 无 ▾ ]
  状态：已安装到这个前缀（d3d11.dll / d3d12.dll 存在）  [重新安装]

前缀
  ( ) 新建   (•) 复制自现有   ( ) 使用已有目录   ( ) 临时（退出即删）
  [ ~/.local/share/lunarward/prefix/hk4e-1        ] [浏览…]
  大小 12.4 GB · 被 2 个方案使用 · 健康           [打开目录]
  ⚠ 换运行器后，下次启动会走一次 wine 更新（wineboot -u）

▸ 高级
  环境变量（每行 KEY=VALUE）…
  调试 Shell：[ bash ▾ ]
  输出：[ 面板 ▾ ]
──────────────────────────────────────────────
                                [ 取消 ] [ 保存 ]
```

要点：

- 前缀选择在**本页**就能看到解析后的绝对路径、大小、占用与共用方案数；`浏览…` 走 `FileDialogHelper.PickFolderAsync`。
- 图形层改变时立刻显示「是否已装进当前前缀」，避免“选了但没装”。
- `保存` 前做一次轻校验：运行器可用、前缀可解析；不可用则就地提示，不弹二次确认。
- 新建方案默认值：运行器 = 当前可用列表第一个、图形层 = 上次用过的、前缀 = 新建（路径 `prefix/<biz>-<id 前 8 位>`）。

## 8. 待确认的小细节（我给默认值）

1. 运行器段默认**折叠**只显示前 5 个？→ 默认全展开，超过 8 个才折叠。
2. 前缀大小扫描是否需要手动触发？→ 进页自动算，但**只算一次**并缓存 10 分钟（大前缀 `du` 有成本）。
3. 方案删除时是否连带删前缀？→ 不连带，改为提示「还有 N 个方案/游戏在用」。
4. 无方案时页面显示什么？→ 空态：「还没有方案，[新建方案]」+ 一行说明。
5. 组件不可用但仍是某方案当前运行器时，是否允许保存？→ 允许保存，但行上常驻红字提示并在启动预检里拦。
