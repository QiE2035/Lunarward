## 四、待用户确认的「执行边界」

以下动作**未经你明确同意不会执行**：

1. 安装系统包（wine/protontricks/umu 等）；
2. 创建 `poc/` 之外的新目录；
3. 修改 `src/` 下任何文件；
4. 执行 `git commit` / `git push`；
5. 下载任何组件（DXVK/Proton）；
6. 读写你的既有前缀（`~/.wine`、anime-game-launcher、sleepy-launcher 的 prefix）。

当前已获授权范围内的事：写 `docs/linux-port/` 文档、`poc/` 门禁实验、`vendor/upstream/` 补全源码、`src/Lunarward/` 新工程移植（`src/Starward/` 不改），以及按 m02240 在 `linux-port` 分支提交。
