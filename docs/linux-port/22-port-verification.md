## 3. 缺陷

### P0-1 窗口按物理像素开，DIP 面积缩水一半（缩放 1.5 下）
- 现象：输出缩放 1.5 时窗口物理 1200x680 → 仅 `800x453 DIP`，而页面按 `1200x676 DIP` 设计。
- 后果：双列页面右列溢出被窗口右缘裁断（游戏设置页「HDR 亮度设置」及说明文字）、底部内容被压、必须滚动才看得全。
- 证据：`cu_windows` 的 client 1200x652；`/tmp/verify/gs-scrolled.jpg`（右列文字在窗口边缘被切断）。
- 判定：与上游「1200 DIP 窗口」不一致，属排版级缺陷。
- 建议修法：窗口初始尺寸以 DIP 声明，再乘 `RasterizationScale`，并按屏幕 90% 夹取；页面对 <900 DIP 宽度降级为单列。

### P1-1 游戏设置页在窄 DIP 下不降级单列
- 根因同 P0-1；`GameSettingPage.xaml` 两列 `Grid` 无宽度断点。

### P1-2 底部「应用 / 重置」栏压住说明文字
- 现象：`游戏运行时应用的设置无法生效` 与底部按钮条重叠。
- 证据：`/tmp/verify/win-gamesetting.png`。

### P2-1 分辨率显示 `0 x 0`
- 已记 F-14（wine 注册表无键时的空值），是否改为「未设置」待定。

### P2-2 滚动条不可见
- 页面可滚（滚轮生效），但无可见滚动条，用户难以判断「下面还有内容」。
