## 3. 缺陷

### P0-1（已更正）窗口按物理像素开，但缩放比例是 1.0 —— 原判断作废
- 更正依据：把窗口从 1200 缩到 900 物理像素后，页面自动变成单列（说明 `SizeChanged` 的宽度单位与物理像素一致，缩放比为 1.0，不存在「DIP 面积缩水」）。
- 因此 1200×680 物理 = 1200×676 DIP，与上游设计尺寸一致；**不需要放大窗口**（用户已明确：现在尺寸合适，放大如「老年机」）。

### P0-2 游戏设置页右列内容溢出窗口右缘（真因待确认）
- 现象：双列时右列「如果有多个显示器…」与 HDR InfoBar 越过窗口右缘被切断；左列正常。
- 已排除：缩放（见 P0-1）。
- 当前假设：`ScrollViewer_Main` 未显式禁用横向滚动，Uno 下可能以无限宽度测量内容，导致 `TextWrapping` 不生效（与 L-97 同族）。
- 需要一次对照实验：加 `HorizontalScrollMode="Disabled"` 后再截图（未获批准，尚未实施）。

### P1-1（已撤回）「窄宽度不降级单列」不成立
- 实测：窗口缩到 900 宽时页面自动单列，断点生效；原判断建立在错误的缩放前提上，作废。

### P1-2（待复核）底部「应用 / 重置」栏与说明文字是否重叠

- 解锁：一次固定尺寸截图 + 逐行像素扫描（未执行）。
